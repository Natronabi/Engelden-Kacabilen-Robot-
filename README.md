# Obstacle Avoiding Robot

An Arduino-based autonomous obstacle detection and avoidance system.

## About
A 2WD autonomous ground vehicle that detects obstacles using an 
HC-SR04 ultrasonic sensor and navigates without collisions.

## Features
- 3-level speed control (full speed / slow / maneuver)
- Real-time distance and status display on 16x2 LCD
- Visual proximity bar on LCD
- Safe maneuver algorithm with maximum 5 retry limit
- Verified with Proteus simulation

## Hardware
- Arduino UNO R3
- HC-SR04 Ultrasonic Sensor
- L298N Motor Driver
- 2x TT DC Gear Motor
- 16x2 LCD Display (LM016L)
- 2WD Robot Chassis Kit
- 1x 9V Battery
